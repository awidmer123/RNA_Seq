# resources

This directory contains external reference material used to guide the RNA-seq
analysis workflow. The files in this directory are not generated by the pipeline
itself but serve as methodological and organizational references.

## Contents

### `DEAnalysisWorkflow.html`
Official RNA-seq differential expression analysis workflow provided by the
university.  
This document outlines recommended analysis steps, quality control procedures,
and reporting requirements and was used as a guideline when designing and
executing the analysis pipeline implemented in this project.

---

## Notes
- Files in this directory are provided for reference only.
- The analysis scripts in this repository follow the general structure and
  recommendations described in the workflow document but may include additional
  steps or project-specific adaptations.
