# 4_Analysis

This directory contains the core downstream analysis scripts used for differential gene expression and functional interpretation of the RNA-seq data. All scripts operate on count matrices generated in earlier pipeline steps and are executed within the R environment.

## Contents and running order

### 1. `Analysis_DESeq2.R`
Main script performing differential gene expression analysis using **DESeq2**.  
It includes data import, normalization, variance-stabilizing transformations, exploratory data analysis (e.g. PCA, heatmaps), and statistical testing for the defined experimental contrasts.

**Output:**  
- DESeq2 result tables (differentially expressed genes)  
- Diagnostic plots (e.g. PCA, volcano plots, heatmaps)

---

### 2. `Important_genes.R`
Script used to extract, track, and visualize a predefined set of immune-related genes of particular interest.  
This includes genes associated with interferon signaling and immune response pathways, which are highlighted across multiple comparisons for interpretative consistency.

**Input:**  
- DESeq2 results generated by `Analysis_DESeq2.R`

**Output:**  
- Subset tables and plots for selected genes

---

### 3. `Analysis_EnrichGO.R`
Script performing Gene Ontology overrepresentation analysis using **clusterProfiler** and related Bioconductor packages.  
It identifies enriched biological processes and pathways among differentially expressed genes and supports functional interpretation of transcriptional changes.

**Input:**  
- DEG lists from `Analysis_DESeq2.R`

**Output:**  
- GO enrichment result tables  
- Enrichment visualizations (e.g. dot plots, bar plots)

---

## Notes
- Scripts should be executed in the order listed above.
- All analyses assume that input count data and metadata have been generated and quality-checked in previous pipeline steps.
- Figures and tables generated here are used directly in the final report.
