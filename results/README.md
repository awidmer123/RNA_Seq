# results

This directory contains all data generated by the RNA-seq analysis pipeline,
including intermediate and final result files.

Due to file size limitations and practical considerations, only a subset of the
results is tracked in the public GitHub repository. Large intermediate files
such as SAM/BAM alignment files, raw count matrices, and other bulky outputs are
excluded from version control.

## Contents

- `multiQC/`  
  Aggregated quality control reports generated by MultiQC.

- `versions/`  
  Documentation of software and R package versions used in the analysis.

- Additional subdirectories (not tracked on GitHub)  
  Contain large intermediate and result files generated during mapping,
  quantification, and downstream analyses.

## Notes
- All results shown in the report were generated from files stored locally or on
  the HPC system.
- Excluding large files from GitHub does not affect reproducibility, as all
  scripts required to regenerate these results are fully documented in the
  repository.
