# versions

This directory documents software and package versions used throughout the
RNA-seq analysis to ensure reproducibility.

## Contents

### `tool_Versions.txt`
Text file listing versions of command-line tools used in the pipeline (e.g.
alignment, quantification, and QC tools).

### `R_package_versions.txt`
Text file listing versions of all R packages used for downstream statistical
analysis and visualization.

---

## Notes
- Version information complements the documented pipeline scripts.
- These files allow the analysis environment to be reconstructed at a later
  time.
